# dikunova

создаем сайт для художника (стильный и современный с галереей, фильтрами, возможность переключения на темную тему, выбором языка, покупкой картины...)
Материалы старого сайта для копирования данных - https://dikunova.art/
Оставляем список меню (список направлений работ делаем в виде списка в фильтрах) переносим имеющиеся работы на новый сайт.
Техническое задание:
1. прелоудер (приложен к запросу) на темном фоне в виде Подписи автора и имени фон в виде  графики автора заглушенного (запоминаем какой язык был ранее выбран пользователем для отображения имени художника)
2. На главной странице: 
- в шапке по центру ставим Имя и фамилию автора
- используем подпись автора (приложена к запросу) на сайте слева в шапке
- меню с адаптацией под мобильные устройства делаем в таком стиле https://www.olivergareis.com и добавляем фамилию, как на этом сайте в подвал чтобы видно было на половину, в дополнение выбираем ключевые достижения в короткую надпись 
- пример оформления галереи с фильтрами берем отсюда с использованием хлебных крошек https://bizar.art/artwork
3. Стилистику, анимацию меню и шрифтовое (посмотри css) используем с этого сайта https://www.olivergareis.com и
